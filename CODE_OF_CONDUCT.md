# Code of conduct

Kyrona is a small project. The standard is the same as a larger one.

## Expected

- Assume good faith.
- Criticise the product, the rules, and the code. Not the person.
- Keep payment details, account names, and screenshots to what the person has already made public.

## Not accepted

- Harassment, slurs, or sexual comments.
- Publishing someone else’s seed phrase, keys, or private balance.
- Opening a public issue for a vulnerability that is still live. Use [SECURITY.md](SECURITY.md).

## Where it applies

Issues, pull requests, and any conversation about this repository.
